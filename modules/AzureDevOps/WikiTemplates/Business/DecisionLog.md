### How to use this log in software delivery

- Record architecture and platform choices as decisions, such as branching strategy, CI/CD design, and security controls.
- Link each row to a detailed Architecture Decision Record (ADR) in the repository when possible.
- Keep the log in the same repository as the code so engineers and stakeholders can track why key technical choices were made.
